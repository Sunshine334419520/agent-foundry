# Agent Harness 学习方法总纲

> 目标：从"会写 demo"到**掌握 Agent Harness 核心知识**——即 [LEARNING_MAP 课程表](opencode-study/LEARNING_MAP.md) 里的每一项（Agent Loop / Session / Agent / Tools / 上下文 / 模型 / 权限…），每项都做到**理论 + 源码 + 实现**三深。

## 三根支柱（三螺旋）

| 支柱 | 学什么 | 在哪 |
|---|---|---|
| ① 理论 | Agent 核心概念（为什么这么设计） | `docs/handbook.md` + `docs/deep-dive/` |
| ② 代码精读 | 读 opencode 源码，**让代码带我们挖出深理论** | `docs/opencode-study/LEARNING_MAP.md`（源码在 `~/code/opencode`） |
| ③ 实践 | 亲手实现我们的 Agent Harness（TS CLI） | `harness/` |

三者互相印证：**理论**讲"为什么"，**源码**讲"生产怎么做"，**harness** 讲"我真的会了"。

## 方法论基石

- **理论从代码中挖出**：阶段 1 的理论只是"子集"，生产代码是"全集"。以代码为大纲，让代码告诉我们涉及哪些核心理论——不拿旧理论去框代码，否则会漏掉大量新理论。
- **理论先行，代码后行**：你读代码依赖理论，所以由我先读代码 + 查最新资料，把完整理论整理给你；你学完理论，再带着理论读代码。**理论是终点，代码是途径，但对你而言理论必须先于代码。**
- 每个核心知识（Agent Loop、Session 管理……）都是一次独立深挖，走下面的**五步推进法**。

## 五步推进法（每个深挖单元）

| 步 | 干什么 | 谁做 | 产出 | 讨论点 |
|---|---|---|---|---|
| **A. 理论梳理** | 通读 opencode 源码 + 查最新理论资料 → 整理成完整理论文档 | 我 | `0X-<主题>.md`（理论篇） | — |
| **B. 理论学习** | 读理论文档，把"为什么"讲透 | 一起 | 你弄懂理论 | ⭐ 卡住就问，讲到点头 |
| **C. 代码精读** | 带着理论逐段精读源码，段段对应 | 我讲你跟 | 代码 = 理论的具体化 | ⭐ 每段停下确认 |
| **D. 实现 harness** | 在 harness 实现这一层 | 一起 | harness 跑通 | ⭐ 实现前先讲设计 |
| **E. 验收 + 笔记** | 独立讲清原理 + 笔记收尾 | 你 | 笔记完成 ✅ | — |

**关键纪律**：每步结束都停下来，确认懂了再进下一步，绝不自动往下冲。**理论不扎实（B）绝不碰代码（C）。**

## 阅读路径

1. **基础**（已完成）：`handbook.md` → `deep-dive/` part1-5 → 亲手写 Python 最小 Agent（`demo/minimal-agent/`）。
2. **主线**：打开 `opencode-study/LEARNING_MAP.md` 的**核心知识清单**，从 #1 开始逐项走五步推进法。
3. **每单元验收**：能讲清"为什么" + harness 对应层能跑 + 笔记落档。

## 为什么是"三螺旋"

单一方式都学不扎实：只看理论会"眼高手低"，只读源码容易"被带跑"，只写代码会"知其然不知其所以然"。三者交替推进——每学一块，都在另外两根柱子上得到印证。
