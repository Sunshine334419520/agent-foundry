# 小红书专栏总纲 —— AI Agent 科普

> 这是本专栏的**宪法**。写任何一篇之前先读这里：定位、人群、写作规范。
> 改这里之前先想清楚——它是后面所有笔记的准绳，乱了整个系列就乱了。

## 一、专栏定位（一句话）

> **《AI 是怎么干活的》—— 用大白话拆开 AI Agent，每个概念一集，看完你就懂了。**

- 不讲"我怎么学 opencode / 怎么手写 harness"的过程（那是自嗨，读者不关心）
- 讲的是 **Harness 架构背后的通用 AI 知识点**——任何 AI Agent 都有的概念
- Harness 只作为"讲得清楚的实例"，用来画图、做类比，**不露代码**

## 二、面向人群（写之前默念）

**会用 AI、但完全不写代码的人。**

- 用过 ChatGPT / Claude / Kimi / DeepSeek，好奇"它到底怎么干活的"
- 可能听说"Agent""MCP"这些词，似懂非懂，想搞清楚
- 收藏、转发、评论是主要互动方式，专业术语是劝退按钮

**不是给谁看的**：程序员、AI 从业者（他们会嫌浅，别管他们，后续可做进阶系列）。

## 三、写作标准规范（铁律，违反即重写）

### 3.1 内容红线

- ✅ 一篇一个知识点，一个生活类比贯穿到底，不讲第二个类比
- ✅ 结论前置：第一句就要让人"啊原来如此"
- ✅ 每个知识点配"它解决什么问题 + 不解决会怎样"（先让读者知道为什么要学）
- ❌ **代码一行都不露**（架构图也要去代码化，函数名全换成图标/图形）
- ❌ 不讲黑话；任何专业词第一次出现必须用大白话解释
- ❌ 不写学习过程、不写"我做了什么"

### 3.2 标题规范

公式：`为什么 / 原来 / 一句话 + 反差 + 悬念`

- ✅《AI 不是"问答机"，它是"自动干活的循环"》
- ✅《为什么 AI 聊久了会"失忆"？》
- ❌《我的 Harness 的 context management 实现》
- ❌ 纯标题党（承诺了内容里必须有，否则取关）

### 3.3 封面与图文规范

- 封面：**大字标题 + 一张图**，小红书 3:4 竖图
- 每张图只讲**一个**观点；文字负责"为什么 + 结论"
- 图优先：能画成图的不写字，能一句话的不写三段
- 正文结构：结论前置 → 展开 → 关键图 → 结尾钩子（"下一篇拆 XX，想看扣 1"）
- 全篇 8 张图左右，一篇一个主图贯穿

### 3.4 结尾钩子（涨粉关键）

每篇结尾必须留一个钩子：预告下一篇 + 引导互动（扣 1 / 收藏 / 评论区问）。

## 四、系列骨架：一篇地图，十篇零件

- **第一篇 = 全景图**：《一张图看懂 AI 技术全景》—— 四层概念结构（模型/记忆/工具/Agent），先给地图
- **后续每篇 = 图上的一个零件**，开头先回地图（高亮"我们现在在哪层"），再讲那个点
- 这样单篇有定位、系列有骨架，读者有追更理由

## 四·五、Harness 在本系列中的位置（内部视角，读者看不到）

> 这是**你**内心的理解，不是讲给读者的知识点。写笔记时用它定位素材，但不出现在读者看到的图里。

- **四个概念层 = 独立的东西**：模型（大脑）、记忆（记得住）、工具（动得了手）、Agent（会自己决定下一步）。上层调用下层，下层不重复出现在上层。
- **四层合起来 = Harness**（Anthropic 官方定义：harness = 循环 + 工具 + 上下文管理 + 护栏，把"原始智能"变成"能工作的 Agent"的那层软件）。
- **Harness + UI + 自定义功能 = 应用**（如 Claude Code、Workbuddy）。Claude Code 不是 Harness——它是应用，里面有一个 Harness 在跑。
- **一句话**：`模型+记忆+工具+循环 = Harness（引擎）`；`Harness + UI + 功能 = 应用（产品）`。
- **你的项目**：`harness/`（loop + tool + session + llm）就是 Harness；`cli/repl.ts` 是外壳。合起来 ≈ 一个迷你 Claude Code。
