## 第一期 · 全景地图篇（01）

### 01 · 《一张图看懂 AI 技术全景》

**作用**：本专栏最重要的笔记。建立整体 AI 知识框架——把 AI 技术分成四层，让读者一眼看清全貌，之后每篇都在这张图上的某个位置。

**概念结构（基于权威框架：Lilian Weng 公式 + Anthropic harness 定义）**：

> 关键认知（先想清楚再画）：
> - **模型/记忆/工具/Agent = 四个独立概念层**，谁也不包含谁（上层调用下层，下层不重复出现在上层）
> - **这四层合起来 = Harness**（Anthropic 官方定义：harness = 循环 + 工具 + 上下文管理 + 护栏，即"把原始智能变成能工作的 Agent 的那层软件"）
> - **Harness + UI + 自定义功能 = 应用**（如 Claude Code、Workbuddy）
> - 大众科普中 Harness 不单独出现——读者只需知道"AI 干活靠 ①-④ 四层拼起来"；Harness 是内部视角

**主图（图 A，俄罗斯套娃式，强调包含关系）**：

```
┌─────────────────────────────────────────────┐
│         应 用  Application（产品）            │
│                                             │
│   ┌─────────────────────────────────────┐   │
│   │      H A R N E S S（引擎）            │   │
│   │      = 循环+工具+记忆+护栏            │   │
│   │                                     │   │
│   │   ┌─────────────────────────────┐   │   │
│   │   │ ④ Agent 层（规划/循环/决策）  │   │   │
│   │   ├─────────────────────────────┤   │   │
│   │   │ ③ 工具层（Tools/Skill/MCP）   │   │   │
│   │   ├─────────────────────────────┤   │   │
│   │   │ ② 记忆层（上下文/压缩）       │   │   │
│   │   ├─────────────────────────────┤   │   │
│   │   │ ① 模型层（LLM 大脑）         │   │   │
│   │   └─────────────────────────────┘   │   │
│   │                                     │   │
│   └─────────────────────────────────────┘   │
│                                             │
└─────────────────────────────────────────────┘
```

**一句话讲透四层**：AI 先有**大脑**（模型，会说话），给它**记忆**（记得住）、**手脚**（工具），再站一个会自己决定下一步的**灵魂**（Agent）——四层合起来是**引擎（Harness）**，加个**外壳**（UI + 功能）就是**产品（应用）**。

**收尾钩子**：接下来我一个零件一个零件拆给你看——先拆"灵魂"，AI 到底怎么自动干活的。

## 第二期起 · 逐零件篇（02-10）

> 每篇都要：① 开头回地图（高亮"我们现在在哪层"）② 一个生活类比贯穿 ③ 结论前置 ④ 结尾钩子。

### 02 · Agent = 循环（④ Agent 层）

- **知识点**：Agent 的本质是一个循环——想→做→看结果→再想，直到完成
- **生活类比**：一个人办事情：做完一步看结果，再决定下一步
- **标题**：《AI 不是"问答机"，它是"自动干活的循环"》
- **图**：一张循环图（想→做→看→再想）；对比"你问它答"一条线 vs "办事循环"一个圈

### 03 · 工具系统 Tools（③ 工具层）

- **知识点**：AI 不会思考，它通过"调用工具"来动手做事（搜索/读文件/运行程序）；描述即接口
- **生活类比**：管家不动手，指挥一堆工具干活
- **标题**：《AI 是怎么"动手做事"的？——它只会指挥工具》
- **图**：AI 中枢 + 一圈工具图标

### 04 · Skill 技能（③ 工具层）

- **知识点**：Skill = 给 AI 插一张"技能卡"，让它照固定流程干活（比工具更"流程化"的知识包）
- **生活类比**：给机器人插一张技能卡，立刻会干新活
- **标题**：《给 AI 插一张"技能卡"，它立刻会干新活》
- **图**：机器人 + 可插拔技能卡槽

### 05 · Plugin 插件（③ 工具层）

- **知识点**：Plugin = AI 的"App"，带界面/带工具的外加能力包
- **生活类比**：手机装 App，扩展能力
- **标题**：《AI 装"插件"，就像手机装 App》
- **图**：手机应用商店 + AI 应用中心

### 06 · MCP 万能接口（③ 工具层）

- **知识点**：MCP = 统一标准协议，让 AI 一次接上所有外部数据/服务（日历/邮箱/数据库），不用逐个对接
- **生活类比**：万能插座，什么插头都能插
- **标题**：《一个"万能插座"，让 AI 接上全世界的数据》
- **图**：插座 + 各种插头（日历/邮件/数据库）

### 07 · 消息 / 记忆（② 记忆层）

- **知识点**：AI 的"记忆" = 每次把整段对话重新读一遍，不是真的记住
- **生活类比**：一个健忘但每次都重读聊天记录的助手
- **标题**：《AI 的"记忆"是个谎言？它每次都在重读聊天记录》
- **图**：对话记录长条图，标出"每次全读一遍"

### 08 · 上下文压缩（② 记忆层）

- **知识点**：上下文有限，聊太长要把旧内容压成摘要（compaction），否则 AI 失忆/超预算
- **生活类比**：记笔记，聊太多就把前面写成要点
- **标题**：《为什么 AI 聊久了会"失忆"？——记忆压缩的秘密》
- **图**：长对话 → 缩成摘要卡片的图

### 09 · 人设 + 权限（④ Agent 层）

- **知识点**：Agent = 人设（prompt）+ 权限（工具白名单）——换人设换权限就是换一个 AI
- **生活类比**：演员：剧本决定怎么演，道具决定能干什么
- **标题**：《同一个 AI，凭什么能当"财务"又能当"文案"？》
- **图**：一个 AI 分裂成多个角色的图

### 10 · 子代理（④ Agent 层）

- **知识点**：一个 Agent 可以派"手下"（子代理）并行干活，再汇总结果
- **生活类比**：老板把任务派给下属，下属各自干活
- **标题**：《一个 AI 还能指挥一群 AI？》
- **图**：主 AI + 分出去的小 AI
