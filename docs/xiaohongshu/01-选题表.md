## 第一期 · 全景地图篇（01）

### 01 · 《WorkBuddy 背后，藏着一台引擎》（图为主，文字为辅）

**作用**：本专栏最重要的笔记。不聊"大模型多聪明"，而是揭开一层大众没听过的东西——**AI 能干活，靠的不只是大模型，而是它背后那台"引擎"（Harness）**。一张图看清全貌，之后每篇都在这张图上的某个位置拆零件。

**这篇讲清楚三件事**（用户核心诉求，就这三件，不加别的）：
1. **Harness 是什么**——模型只会"说话"，让它"干活"的那层软件 = Harness
2. **Harness 怎么来的**——不是谁发明的，是模型越来越强、逼出来的（Prompt 时代 → Context 时代 → Harness 时代）
3. **Harness 的架构 / 核心内容**——核心是一个循环（Agent Loop：想→做→看→再想），循环外挂一圈能力零件（Tool Call / MCP / Skill / Memory / SubAgent），最外层一道护栏（Hook / Goal）；Anthropic 官方叫"循环 + 工具 + 上下文管理 + 护栏"

**形式铁律（小红书）**：**图为主，文字为辅。** 每张图是一张"信息卡"：图中大字说结论，少量文字做标注；全篇不出现大段文字。图与图之间有叙事递进。

#### 图 3 · Harness 怎么来的（时间线三步演进）
- **画面**：一条从左到右的时间线，三个节点卡片
  - **2020-2024 · Prompt 时代**：模型不听话 → 教它"怎么输出"

  - **2026- · Harness 时代**：模型够强了 → 给它"一套环境"，约束行为、组织能力
- **图中大字**：不是谁发明了引擎，是模型越来越强，逼出了这层软件
- **图中小字**：模型越强，外面这层环境就越重要

#### 图 4 · Harness 的架构（核心是 Agent Loop，围绕它挂一圈设施；本专栏的地图）
- **画面**：中心一个"循环环"（Agent Loop：想 → 做 → 看结果 → 再想），环心是"模型大脑"；环外辐射挂一圈能力零件（Tool Call / MCP / Skill / Memory / SubAgent），最外层一道虚线"护栏"（Hook / Goal）包住整台引擎。图见下方主图 A
- **图中大字**：引擎的核心，是那个"循环"
- **图中小字（一句一个零件）**：
  - 核心 · Agent Loop：想 → 做 → 看 → 再想（所有框架共享的 ReAct 内核）
  - 大脑 · 模型 LLM：听懂 + 说话，驱动每一轮"想"
  - 手脚 · Tool Call：读写文件、跑命令等原子操作
  - 插座 · MCP：接上外部数据/服务，不用逐个对接
  - 技能卡 · Skill：照固定流程干活（比工具更"流程化"）
  - 记事本 · Memory：跨会话记得住偏好和教训
  - 手下 · SubAgent：派独立上下文的小弟并行干活
  - 护栏 · Hook / Goal：用代码/目标强制约束，模型绕不过
- **图中小字（底部）**：下面几篇，我一个零件一个零件拆给你看
